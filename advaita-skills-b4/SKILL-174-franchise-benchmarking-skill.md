# SKILL-174: Franchise System Benchmarking
**Version:** 1.0 | **Pillar:** Franchise Lifecycle | **Reversibility:** REVERSIBLE

## PURPOSE
Benchmark SRP franchise system metrics vs industry standards. Identify competitive positioning and system health.

## TRIGGER
Annually (January) OR before FDD annual update.

## EXECUTION STEPS
1. Pull SRP system-wide metrics from QB + GHL:
   - Average unit volume (AUV)
   - Franchisee retention rate
   - New unit opening rate
   - Royalty collection rate
   - Net Promoter Score (franchisee)
2. Run Exa: sports retail franchise industry benchmarks
3. Compare SRP vs industry:
   - AUV vs category average
   - Franchisee retention vs industry
   - Royalty rate vs comparable systems
4. Generate benchmarking report
5. Flag gaps that may need FDD Item 19 consideration (legal review required)
6. Upload to Drive: `fki-franchise/benchmarking-[year].md`
7. Post summary to #leo-auto

## DIAMOND GATE
- T1: Industry benchmarks labeled as external data. Legal review flag ✅
- T2: File > 200 bytes ✅
- T3: Research and reporting only ✅
