# SKILL-180: Lead Magnet Builder
**Version:** 1.0 | **Pillar:** AI Marketing Content | **Reversibility:** REVERSIBLE

## PURPOSE
Build high-converting lead magnets for FKI brands: guides, checklists, assessments, toolkits, mini-courses.

## TRIGGER
Bennett says "lead magnet [brand] [topic]" OR quarterly marketing refresh.

## EXECUTION STEPS
1. Run bennett-intelligence-layer-skill for brand/offer context
2. Determine lead magnet type based on audience awareness level:
   - Low awareness: problem-aware guide ("Are you making these 5 mistakes?")
   - Medium awareness: solution-aware checklist ("The [brand] quick-start system")
   - High awareness: offer-ready assessment ("Is [program] right for you?")
3. Generate full lead magnet content:
   - Title + subtitle (pattern interrupt + benefit)
   - 5-7 high-value sections
   - Visual layout notes
   - CTA at end (book call / apply / shop)
4. FDD qualifiers on results
5. Upload to Drive: `fki-content/lead-magnets/[brand]-[slug]-[date].md`
6. Post to #leo-auto with type + audience level + Drive link

## DIAMOND GATE
- T1: FDD qualifiers on results. No income claims ✅
- T2: File > 200 bytes ✅
- T3: Content document — no landing page auto-publish ✅
