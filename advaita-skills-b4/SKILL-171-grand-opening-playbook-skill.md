# SKILL-171: Grand Opening Playbook Generator
**Version:** 1.0 | **Pillar:** Franchise Lifecycle | **Reversibility:** REVERSIBLE

## PURPOSE
Generate complete grand opening playbook for new SRP franchisees. Local marketing, PR, and launch event planning.

## TRIGGER
SRP franchisee reaches 60-day onboarding milestone (location confirmed + training complete).

## EXECUTION STEPS
1. Pull franchisee location data from GHL/Drive
2. Load grand opening template from Drive: `fki-franchise/grand-opening-template.md`
3. Customize for franchisee market:
   - Local media contacts (Exa search: local sports media in market)
   - Local sports organizations to partner with
   - Social media launch sequence (30/14/7/1 day countdown)
   - In-store event ideas (clinics, demos, athlete appearances)
   - PR release draft (no earnings claims)
4. Build 30-day pre-launch + 7-day post-launch marketing calendar
5. Upload to Drive: `fki-franchise/grand-openings/[franchisee-id]-playbook.md`
6. Post to #leo-auto: franchisee + location + planned opening date

## DIAMOND GATE
- T1: No revenue projections in grand opening materials ✅
- T2: File > 200 bytes ✅
- T3: Playbook document — no financial commitments ✅
