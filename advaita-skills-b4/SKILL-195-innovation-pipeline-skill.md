# SKILL-195: Innovation Pipeline Manager
**Version:** 1.0 | **Pillar:** Advanced Intelligence | **Reversibility:** REVERSIBLE

## PURPOSE
Capture, evaluate, and prioritize new product/service ideas for FKI. Prevent good ideas from getting lost. Move the best ones to launch.

## TRIGGER
Bennett says "add to pipeline: [idea]" OR monthly idea review.

## EXECUTION STEPS
1. Log new idea to Drive: `fki-innovation/idea-log.md` (append)
   - Idea description
   - Source (Bennett / coaching client / market research)
   - Date added
2. Monthly review: score all unvetted ideas:
   - Market demand (Exa research): 1-5
   - Alignment to FKI strengths: 1-5
   - Revenue potential (estimate): 1-5
   - Time to market: 1-5 (higher = faster)
   - Resource requirement: 1-5 (higher = lower cost)
3. Composite score → rank
4. Top 3 ideas: generate one-pager brief (problem / solution / market / build cost estimate / go-to-market)
5. Upload to Drive: `fki-innovation/shortlist-[date].md`
6. Post to #leo-auto: top 3 ideas by score

## DIAMOND GATE
- T1: Ideas and analysis — no guaranteed outcomes ✅
- T2: File > 200 bytes ✅
- T3: Log and rank — no build commitments ✅
