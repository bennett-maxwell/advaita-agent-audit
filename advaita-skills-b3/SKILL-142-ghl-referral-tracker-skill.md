# SKILL-142: GHL Referral Tracker Automation
**Version:** 1.0 | **Pillar:** GHL Deep Automation | **Reversibility:** REVERSIBLE

## PURPOSE
Track referral activity across FKI brands in GHL. Identify top referrers, calculate referral value, automate thank-you sequences.

## TRIGGER
Weekly Wednesday 8 AM MDT (auto).

## EXECUTION STEPS
1. Pull GHL contacts: source = referral (last 30d)
2. Map: referrer (from UTM ref param or GHL referred_by field) → referred contacts
3. Calculate per referrer:
   - Total referrals
   - Conversion rate (referred → enrolled)
   - Revenue generated by referrals
4. Top 5 referrers: trigger thank-you email + VIP tag in GHL
5. Log referral data to Drive: `fki-ops/referral-report-[date].md`
6. Post top referrers to #leo-auto (name + referral count + value)

- T3: Tags + emails REVERSIBLE ✅
