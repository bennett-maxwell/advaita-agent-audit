# SKILL-110: Influencer Outreach Automation
**Version:** 1.0 | **Pillar:** Marketing Automation | **Reversibility:** REVERSIBLE

## PURPOSE
Identify, score, and draft outreach for micro-influencers in FKI verticals (pickleball, fitness, sports coaching). Builds pipeline for UGC partnerships.

## TRIGGER
Bennett says "find influencers for [brand]" OR monthly autopilot.

## EXECUTION STEPS
1. Run Exa search for niche influencers (10K-100K followers, >3% engagement rate)
   - IC: pickleball, tennis, paddle sports
   - SH: fitness, sports performance, coaching
   - SRP: sports retail, athlete gear, training equipment
2. Score each (1-10): follower count, engagement rate, audience match, content quality
3. Draft personalized outreach DM (Instagram/TikTok) for top 10 per brand
4. No sending — draft only, log to GHL as "influencer-outreach" pipeline
5. Upload prospect list to Drive: `fki-marketing/influencers-[brand]-[date].md`
6. Post top 5 per brand to #leo-auto for Bennett review

## DIAMOND GATE
- T1: No guaranteed partnership outcomes ✅
- T2: File > 200 bytes ✅
- T3: Drafts only — no sends ✅
